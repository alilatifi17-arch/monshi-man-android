منشی من - ساخت APK بدون Android Studio

این نسخه برای GitHub Actions آماده شده است.

مراحل:
1) وارد github.com شوید و یک Repository جدید بسازید.
2) همه فایل‌های داخل پوشه MonshiManAndroid را در ریشه Repository آپلود کنید.
3) از بالای مخزن وارد تب Actions شوید.
4) Workflow با نام Build Monshi Man APK را باز کنید.
5) Run workflow را بزنید.
6) بعد از سبز شدن Build، پایین همان صفحه بخش Artifacts ظاهر می‌شود.
7) MonshiMan-APK را دانلود کنید.
8) فایل ZIP خروجی را باز کنید؛ داخل آن app-debug.apk است و روی اندروید قابل نصب است.

نکته:
- خود اپ بعد از نصب برای کار روزمره اینترنت لازم ندارد.
- اینترنت فقط برای مرحله Build ابری در GitHub لازم است.
- این خروجی Debug است و برای نصب شخصی مناسب است.
