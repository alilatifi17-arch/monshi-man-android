منشی من – نسخه اندروید 1.0

این پروژه از نسخه HTML «منشی من» ساخته شده و برای Android طراحی شده است.

تغییرات اصلی این نسخه:
- یوزرنیم و پسورد کاملاً حذف شده است.
- ورود مستقیم به برنامه.
- دو شاخه اصلی «شخصی» و «کاری».
- ساخت، تغییر نام و حذف زیر‌بخش‌های دلخواه.
- ثبت یادآوری با عنوان، توضیح، تاریخ شمسی و ساعت.
- تکرار: یک‌بار، روزانه، روزهای خاص هفته، هفتگی، ماهانه و هر چند ساعت.
- ثبت سریع با ویس.
- ضبط و پخش ویس به‌صورت محلی روی گوشی.
- آلارم بومی Android با AlarmManager، حتی وقتی صفحه برنامه بسته است.
- دکمه‌های اعلان: انجام شد، ۱۵ دقیقه بعد، ۱ ساعت بعد، فردا و انجام نشد.
- زمان‌بندی مجدد آلارم‌ها بعد از روشن شدن مجدد گوشی.
- گزارش روزانه و خلاصه شبانه (پیش‌فرض ساعت ۲۲:۰۰).
- پشتیبان‌گیری ZIP شامل اطلاعات برنامه و فایل‌های صوتی.
- بدون سرور، بدون سایت، بدون GitHub و بدون نیاز به اینترنت.
- برنامه عمداً مجوز INTERNET ندارد.

مجوزهایی که Android ممکن است درخواست کند:
- Notifications: برای نمایش اعلان یادآوری.
- Alarms & reminders / Exact alarms: برای هشدار دقیق در ساعت تعیین‌شده.
- Microphone: فقط وقتی خود کاربر ضبط ویس را شروع می‌کند.

ساخت APK با Android Studio:
1) Android Studio را باز کنید.
2) Open را بزنید و پوشه MonshiManAndroid را انتخاب کنید.
3) اجازه دهید Gradle Sync انجام شود. برای اولین Sync، کامپیوتر ممکن است برای دانلود SDK/Gradle به اینترنت نیاز داشته باشد.
4) از منوی Build > Build App Bundle(s) / APK(s) > Build APK(s) استفاده کنید.
5) APK دیباگ معمولاً در مسیر زیر ساخته می‌شود:
   app/build/outputs/apk/debug/app-debug.apk

مشخصات پروژه:
- Application ID: com.atlas.monshi
- Minimum Android: 8.0 (API 26)
- Target SDK: 35
- زبان رابط: فارسی / RTL
- ذخیره اطلاعات: محلی روی گوشی

نکته:
این پوشه سورس کامل Android Studio است. در محیط فعلی ChatGPT ابزار Android SDK/Gradle نصب نبود، بنابراین APK کامپایل‌شده داخل بسته قرار نگرفته است؛ اما پروژه برای باز شدن و Build شدن در Android Studio آماده شده است.
